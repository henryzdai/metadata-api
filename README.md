# Metadata API

Domain types and a storage contract for Applications and their recorded creators.
This revision contains the model and validation tests, not a runnable HTTP server.

## Check the domain

Use Go 1.27.2. The module requires Go 1.26 or later.

```powershell
go test .\internal\metadata -count=1
```
